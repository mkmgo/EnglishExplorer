The Simple Past Tense / Plot Comprehension

Used for ACTIONS COMPLETED IN THE PAST

1. Regular Verbs

Add -ED to the base form (Verb + ed)

  • Rule 1: Just add -ED
  • (e.g., play -> played, start -> started)
  • Rule 2: If it ends in E, just add -D
  • (e.g., love -> loved, smile -> smiled)
  • Rule 3: If it ends in consonant + Y, change Y to I + ED
  • (e.g., study -> studied, cry -> cried)
  • Rule 4: If it ends in certain consonants, repeat it + ED
  • (e.g., drop -> dropped)

2. Irregular Verbs

They CHANGE completely. (They do NOT follow the -ed rule!)

  • be (am/is/are) -> WAS / WERE
  • (e.g., She was happy.)
  • go -> WENT
  • (e.g., They went home.)
  • have -> HAD
  • (e.g., I had breakfast.)
  • do -> DID
  • (e.g., He did his homework.)
  • run -> RAN
  • (e.g., We ran fast.)
